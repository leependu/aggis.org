Discography of American Historical Recordings: Recording Locations
In early 2026 the ArcGIS Online "Web AppBuilder" (the framework upon which the original DAHR map application was built) began its course towards deprecation. I was tasked with producing a new version of the map application.

Embedded below is this "DAHR Recording Locations" Instant App. This app allows users to explore nearly 1,000 recording locations associated with matrix recordings documented in DAHR.

The map's informational sidebar will display details about each location, and provide a link to a matrix search on DAHR that will return all recordings captured at that location.
